# Balbooa Forms 2.x Language Packs

Official language packs for **[Balbooa Joomla Forms](https://www.balbooa.com/joomla-forms)**.

This repository contains the language files used by Balbooa Forms. Language packs are maintained automatically and are updated as the Forms extension evolves.

<br>

> **This repository is automatically maintained.**
> Language files should not be edited manually.

<br>
<br>

## 📥 Installing a Language

Language packs are **not installed directly from this GitHub repository**.

Languages are installed from inside **Balbooa Forms** in your Joomla administrator panel.

For step-by-step instructions, see:

**[Localization and Translation — Balbooa Forms](https://www.balbooa.com/help/joomla-forms-documentation/basics/localization-and-translation)**

<br>
<br>

## 🌏 Need Another Language?

Don't see the language you need?

[Contact Balbooa](https://www.balbooa.com/help/contacts) and tell us which language you would like to have available.

We will consider adding it to the available language packs.

<br>
<br>
